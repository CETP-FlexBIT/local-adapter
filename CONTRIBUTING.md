# Contributing

This repository contains public documentation, installation scripts, releases,
and the linked container package. Application source and tests are maintained in
the private `nextmultiservice/local-adapter` repository.

Report bugs or suggest documentation changes through public issues. Include the
adapter version, deployment mode, reproduction steps, and expected behavior.
Remove credentials and private telemetry from logs and screenshots.
Report vulnerabilities using [SECURITY.md](SECURITY.md).

Maintainers edit documentation and installation scripts in the private repository.
An allowlisted export updates this repository. Direct changes here can be
overwritten by the next sync.

Contributions are provided under the [Apache-2.0 license](LICENSE).
